# Workflow correctness regression scenarios

These are manual contract checks for the skill instructions. The response fragments combine fields
and states documented in the linked public Surfer REST references; no authenticated calls were made.
Run each scenario against a reader following the workflow and verify the expected next action.

| Scenario and input | Expected next action | Contract evidence |
|---|---|---|
| After a content update, editor GET returns `"content_score": {"total": 75, "seo": 75, "ai_search": 62}` while SEO score GET returns `{"status":"calculating","score":75,"calculated_at":"2026-05-27T10:23:11Z"}`. | Treat 75 as a possibly stale total snapshot; keep polling the selected subscore. Never inspect `total.status`. Once its status is `ready` and timestamp advances, re-read the editor. | [Content Editors](https://app.surferseo.com/llms/content-editors.txt), [SEO Guidelines](https://app.surferseo.com/llms/seo-guidelines.txt) |
| AI Search facts returns `{"data":[],"meta":{"status":"executing","total":0}}`. | Wait for analysis `meta.status: completed` or report `failed`; do not request page 2 or assume a ready score. Read the separate score endpoint when a score is needed. | [AI Search](https://app.surferseo.com/llms/ai-search.txt) |
| A brief requests facts while the AI Search score is `ready` but facts `meta.status` is `executing`. | Keep the brief's facts section pending for a bounded wait. Use facts only at analysis `completed`; report failure or timeout if they never settle. The score does not make facts ready. | [AI Search](https://app.surferseo.com/llms/ai-search.txt) |
| Auto-Optimize POST times out after a prior latest job had `job_id: 123`. A latest-job GET now returns `{"job_id":124,"state":"executing"}`. | Poll job 124 by ID. Do not repeat POST or attach an unadvertised idempotency header. | [Auto-Optimize](https://app.surferseo.com/llms/auto-optimize.txt), [MCP credits and retries](https://devs.surferseo.com/mcp/credits-and-limits) |
| Auto-Optimize POST times out and bounded latest-job reads still return job 123 or 404. | Report an indeterminate start. A missing new job is not proof that the POST failed; do not automatically repeat it. | [Auto-Optimize](https://app.surferseo.com/llms/auto-optimize.txt), [MCP credits and retries](https://devs.surferseo.com/mcp/credits-and-limits) |
| A write recommendation or accepted brief passes `content_editor_id: 456` in workspace 7. Editor GET confirms the intended keyword, and AI Article list contains article 88 in `writing` state. | Reuse editor 456 and rejoin article 88. Do not create an editor or start another article. If editor scope or keyword mismatches, report that before generating. | [Content Editors](https://app.surferseo.com/llms/content-editors.txt), [AI Articles](https://app.surferseo.com/llms/ai-articles.txt) |
| AI Article generation returns `409` with `error.details[0].active_article_id: 88`. | Read article 88 and continue its state; do not immediately repeat generation. | [AI Articles](https://app.surferseo.com/llms/ai-articles.txt) |
| AI Article generation loses its response, then bounded `ai_article__list` reads still show no identifiable article. | Report generation as indeterminate and stop. An empty read-back does not prove no article was created or authorize another generation request. | [AI Articles](https://app.surferseo.com/llms/ai-articles.txt), [MCP credits and retries](https://devs.surferseo.com/mcp/credits-and-limits) |
